# Contributing

Thanks for helping with Xenon. Bug reports, ideas and pull requests are welcome.

## Licensing of contributions

Xenon is licensed under the [GPLv3](LICENSE). Carbon Software Ltd may also offer Xenon under a
separate commercial license, which means it needs the right to relicense the code it ships.

So before a code contribution can be merged, you'll be asked to sign a Contributor License
Agreement (CLA) granting Carbon Software Ltd that right. You keep the copyright to your work, and
it stays available under the GPLv3. Issues, discussion and docs fixes don't need a CLA.

## Development

See the README for building and testing. Please run `cargo fmt --all`,
`cargo clippy --workspace --all-targets` and `cargo test --workspace` before opening a PR.
